CSS Animation Properties

1. Basic Animation (Slides Right)

@keyframes slideRight {
  from { transform: translateX(0); }
  to { transform: translateX(200px); }
}

.slide-animation {
  animation-name: slideRight;
  animation-duration: 3s;
}
Slide

2. Infinite Animation (Bounces Forever)

animation-name: bounce;
animation-duration: 1s;
animation-iteration-count: infinite;
Bounce

3. Direction Animation (Forward & Backward)

animation-direction: alternate;
animation-iteration-count: infinite;
Alt

4. Timing Function (Smooth Acceleration)

animation-timing-function: ease-in-out;
Ease

5. Animation Shorthand (Spins)

animation: spin 2s linear infinite;
/* name duration timing-function iteration-count */
Spin

6. Multiple Animations (Spin + Pulse)

animation:
  spin 3s linear infinite,
  pulse 1s ease-in-out infinite;
Multi

7. Hover Animation (Hover Over Box)

.hover-box:hover {
  transform: scale(1.1) rotate(5deg);
  transition: all 0.3s ease;
}
Hover

Hover your mouse over the box!

8. Button Animations

transition: all 0.3s ease;

:hover { transform: translateY(-2px); }
:active { transform: translateY(0); }

9. Loading Spinner (Practical Example)

.spinner {
  border: 4px solid #f3f3f3;
  border-top: 4px solid #007bff;
  border-radius: 50%;
  animation: spin 1s linear infinite;
}
