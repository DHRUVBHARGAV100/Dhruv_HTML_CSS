Flexbox

What is Flexbox?

Flexbox is a CSS layout method that makes it easy to:

  • Align items horizontally and vertically
  • Distribute space between items
  • Create responsive layouts without floats
  • Reorder items without changing HTML

Before Flexbox (Old Way):

Using floats, positioning, and table-cell was complicated and limited

Flex Item Properties (Children)

1. flex-grow (How much should item grow?)

Controls how much space an item should take up

grow: 0
grow: 1
grow: 2

Item with flex-grow: 2 is twice as wide as flex-grow: 1

2. flex-shrink (How much should item shrink?)

Controls how much an item shrinks when space is limited

shrink: 0
shrink: 1

flex-shrink: 0 prevents shrinking, flex-shrink: 1 allows shrinking

3. flex-basis (Initial size before growing/shrinking)

basis: auto
basis: 100px
basis: 200px

flex-basis sets the initial size before flex-grow/shrink is applied

4. align-self (Individual alignment)

Overrides align-items for individual items

normal
self: center
self: end
self: stretch

align-self controls individual item alignment
